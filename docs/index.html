Every AI coding chat on your PC, in one place.

ChatVault is a small desktop app that finds the chats Claude Code, Codex, Cursor, Gemini CLI, OpenCode and Cline already keep on your computer, from every account you have used, so you can read them, search them, back them up and pick the work up again in any tool.

Your chats are still on your computer. ChatVault shows them.

AI coding tools save every conversation on your PC, but each one only shows the chats of the account that is signed in right now. Sign out, switch accounts or reinstall, and your history seems to vanish, even though the files are still there.

ChatVault reads those files, lists them in one fast window and keeps a private search index on your PC. It never uploads your chats and needs no sign-in.

  • Free and open source. MIT licence, built in the open on GitHub. No subscription, no ads, no tracking.
  • Lightweight. An installer of about 4 MB that uses the WebView2 runtime already in Windows.
  • Private by design. Your chats, index and backups stay on your PC. The only connection it makes is a check with GitHub for a new version.
  • Read only by default. It reads your chat files and never touches the sign-in files of your tools.

Everything you need to keep your AI chats

Read, find, keep and reuse every conversation, whichever tool or account it came from.

Read every chat

Open any conversation with its messages, plans, tool steps, code and tables, from every account you have ever signed in with.

Search all tools at once

Full-text search across every tool with Ctrl + K, and find inside the open chat with Ctrl + F.

Back up and restore

Copy your chats to a backup folder you choose, back up automatically, and restore missing chats without overwriting anything.

Continue in any tool

Hand a chat off to another tool. A handoff file carries the whole conversation, so the next tool starts where you stopped.

Export

Save any chat as Markdown, HTML, plain text or JSON to share it, archive it or keep it in your notes.

Automatic updates

New versions download in the background from GitHub, are checked against a signature, and install when you restart.

Works with the tools you already use

Switch each tool on or off in Settings and see exactly which folder its chats are read from.

Private by default

Your conversations can hold source code, file paths and secrets. ChatVault treats them that way: it works on your PC, with no account and no server of ours in between.

Read the Privacy Policy

  • No uploads. Chats, the search index and backups never leave your computer.
  • No analytics or ads. ChatVault does not track how you use it.
  • One network call. A check with GitHub for a new version, and the download if there is one.
  • Optional cloud backup, later. A Google Drive backup is planned. It will be off until you connect it, and it will only touch the backup files ChatVault creates in your own Drive.
